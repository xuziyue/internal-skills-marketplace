# MVP Scope (4-6 Weeks)

## In scope

- Single repository with many skill folders.
- Skill metadata schema and validator.
- Generated catalog index from skill folders.
- Simple web UI for discovery and detail view.
- CLI commands for install and update checks.
- Warning-only policy checks.
- Basic CI validation.

## Out of scope

- SSO or enterprise identity integration.
- Signed provenance enforcement.
- Dual approval and hard-block policy enforcement.
- Automated upgrade PR bot.
- Deep analytics dashboards.
