# SQL to PySpark Converter

This skill converts SQL statements into PySpark DataFrame code and applies practical optimization patterns for memory efficiency and execution speed.

- Migrate SQL logic to PySpark jobs
- Build scalable batch transformations
- Improve Spark job runtime and memory behavior

## Output style
